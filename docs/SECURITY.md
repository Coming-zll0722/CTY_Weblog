# 安全与保密检查清单

## 已实现的应用控制

- [x] Argon2id 密码哈希，初始密码至少 12 位。
- [x] 短期 HttpOnly、SameSite Cookie；生产环境启用 Secure。
- [x] 双提交 CSRF Token，所有管理写请求强制校验。
- [x] 服务端管理员角色验证，密码修改后旧会话失效。
- [x] 登录按客户端和账号两个独立维度限流，失败响应不泄露账号是否存在。
- [x] 严格 CORS 配置，不允许凭据模式使用通配符。
- [x] Markdown 默认禁用原始 HTML，经过白名单清洗；Mermaid 使用 strict 安全模式。
- [x] SQLAlchemy 参数化查询，路由不拼接 SQL。
- [x] 图片校验扩展名、MIME、文件头、大小、尺寸和存储路径。
- [x] 随机媒体存储名，上传/备份目录不进入 Git。
- [x] 文章发布和项目公开前强制保密检查，编辑使用版本字段防止覆盖。
- [x] 日志不记录密码、Token、Cookie、正文和原始邮箱。
- [x] Nginx 安全头、HTTPS、登录限流和请求体大小限制。
- [x] PostgreSQL 自定义格式备份、SHA-256 记录；恢复只允许指向隔离数据库。
- [x] JWT 校验签发者和受众；生产环境限制 Host 并验证请求 ID。
- [x] Python 生产/开发依赖固定版本并使用包哈希校验。

## 上线前必须完成

- [x] 运行时代码不含示例域名或邮箱；公开联系方式来自环境或后台白名单设置。
- [ ] 使用密码管理器生成管理员密码和至少 32 字节应用密钥。
- [x] Nginx 与应用同时限制登录速率。
- [ ] 对依赖运行漏洞检查并处理高危问题。
- [ ] 确认 PostgreSQL、FastAPI、前端端口仅绑定回环或内部网络。
- [ ] 执行一次隔离环境恢复演练，记录 RPO/RTO。
- [ ] 按实际第三方资源收紧 CSP；当前配置允许 HTTPS 图片。

## 发布内容保密审查

- [ ] 未出现公司或客户未公开名称。
- [ ] 未出现真实产品型号、设备编号或内部网络拓扑。
- [ ] 未复制内部源代码、协议原文、测试数据和日志。
- [ ] 未暴露 IP、端口、账号、令牌、文件路径和服务器信息。
- [ ] 未使用未经授权的系统或设备截图。
- [ ] 架构图已重新绘制，不能反推出内部组织和真实部署。
- [ ] 数据帧、地址、名称和时间已模拟或泛化。
- [ ] 项目结果未披露合同、数量、性能和质量敏感指标。
- [ ] 图片已移除定位、设备等元数据。
- [ ] 发布者完成二次复核；不确定内容默认不发布。

## 已知边界

- 应用登录限流存于单个 API 进程内；生产 Dockerfile 固定为一个 Uvicorn worker。扩展为多副本前必须先采用可共享的限流存储。
- 评论和密码找回默认关闭；启用前需要反垃圾、审核、邮件安全和滥用处理。
- `.openai/hosting.json` 仅为历史 Sites 关联；正式域名不通过 Sites 或 Cloudflare 提供服务。
- 备份卷不是异地备份；生产环境仍需加密复制到独立存储。
- Vinext 当前通过内联脚本传输服务端组件数据，因此示例 CSP 的 `script-src` 暂含 `'unsafe-inline'`；框架接入稳定 nonce 后应移除该项。
