# 顶部导航与显示设置调整

2026-11-15，导航调整及发布前验证记录。

- 顶部导航移到正文容器外，通栏吸顶，内部仍与正文宽度对齐。
- 技术栈与时间轴加入顶部导航；搜索、显示设置、管理按顺序排列为图标。
- 显示设置独立弹窗，包含外观颜色和页面布局，保留本地保存、键盘焦点循环、关闭后焦点恢复及窄屏桌面布局恢复功能。
- 手机端保留顶部工具图标和导航菜单。小于 960px 时收起文字导航。
- 移除笔记、资源页面、导航入口与站点地图条目。原地址返回 404，文章、公开链接数据及后台功能未删除。

## 验证

- 生产构建、TypeScript、ESLint 通过。
- `npm test`：9 项服务端渲染/包体检查和 23 项组件测试通过。
- 本地预览使用 `scripts/preview-ui.mjs`。针对这种相对客户端 API 地址的预览构建，SSR 测试需设 `API_BASE_URL=http://127.0.0.1:8765/api/v1`；请求由测试中的模拟 API 接管。
- 浏览器检查：滚动后导航顶边与左右边完整覆盖；桌面、平板及手机布局没有横向溢出；设置弹窗、深色外观刷新保存、桌面布局刷新保存和恢复自动布局、技术栈与时间轴跳转通过。检查期间无浏览器错误日志。
- 完整 FastAPI → React SSR 集成检查通过，21 项 Playwright 回归用例全部通过，包括滚动吸顶、工具图标顺序、手机布局、外观保存、页面跳转与可访问性检查。
- 未修改数据库、认证或生产部署。
