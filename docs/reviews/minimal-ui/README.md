# 极简 UI 改造与本地验证 · 2026-11-03

首页按提供的参考图重排为白底、紧凑简介、三行近况、文章与项目双栏及横向个人介绍。主内容的列宽约为 56:44，保留 64px 栏间空白；1440px 视口内容宽度为 1240px。主标题 40px、栏目标题 20px、条目标题 18px、正文 15px、辅助文字 13px。项目使用 #F5F5F7 浅灰卡片，蓝色操作使用 #0071E3，浅蓝选中背景上的文字加深为 #0066CC 以满足对比度要求。

## 内容与功能

- 最新四篇文章和两个代表项目均来自现有公开 API。保留完整真实标题、日期、摘要和项目标签；没有写入参考图里的示例内容，没有生成产品截图。
- 三行近况沿用 `data/profile.ts` 的 `currentFocus`，不是新增进度或实时活动推断。
- 顶部保留首页、文章、项目、关于和搜索。笔记、资源、技术栈、时间轴、显示设置、外观切换和管理入口在页脚及移动菜单中可达。
- 既有个人资料及长期目标移到关于页；原数据文件与其他组件保留。联系、订阅、备案信息和详情页保持可用。
- 文章、项目、关于及详情页沿用统一颜色、字号和间距。手机自动单栏；用户主动选择的桌面布局及恢复自动布局功能继续保留。
- 未修改后端业务、数据库、权限、API 契约或站点名称。

## 本地预览

在仓库目录运行：

```powershell
node scripts/preview-ui.mjs
```

构建完成后打开 `http://127.0.0.1:3010`。脚本占用本机回环地址的 3010/3011 端口，使用现有公开 API 的真实内容；只转发公开 GET 请求，浏览统计请求在本地结束，管理写入被拒绝。不会把预览操作写入生产数据库。结束时按 Ctrl+C。代码修改后需要重新运行脚本。

Windows 预览复用现有集成测试中针对 Vinext 0.0.50 静态文件查找的修补方法，仅修改未跟踪的构建产物，不改依赖或生产代码。开发模式曾出现内容请求渲染错误，因此截图与交付预览使用正式构建的 Node 服务。
