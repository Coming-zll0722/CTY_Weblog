# 长期内容体系

## 内容类型

技术教程、项目开发日志、问题排查记录、架构设计、工具教程、学习笔记、项目复盘、年度总结、技术路线规划、读书笔记、面试知识整理和工程实践经验。

## 运营节奏

- 每两周：一篇可独立解决问题的工程文章；
- 每月：一次项目进展或学习路线更新；
- 每季度：整理一个完整项目案例并复核旧文章；
- 每年：年度复盘、技术方向调整和陈旧内容归档。

## 质量标准

每篇文章至少包含明确问题、边界、方案依据和验证结果。代码必须可解释；数字必须有来源；工作经验必须脱敏。标题不使用夸张承诺，摘要说明读者能获得什么。
